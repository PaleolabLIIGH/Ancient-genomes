## 32.2 Modify and run the script
Create a new directory to store the output files generated by trimAl, and navigate into it

```bash
mkdir trimal
cd trimal
```
Once inside the new directory, run the script. This script automatically applies multiple filtering methods with trimAl, generating a separate directory for each method.
**Make sure to update the *INPUT* variable path so it points to your previously generated MAFFT alignment file.**

```bash
sbatch trimal.sh
```

```bash
#!/bin/bash
#
#Created by Itzy Perez-Alvarado
#SBATCH --job-name=trimAl
#SBATCH --output=%x.out
#SBATCH --error=%x.err
#SBATCH --mail-type=END
#SBATCH --mail-user=danitzy2004@gmail.com
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=17
#SBATCH --mem-per-cpu=5G
#SBATCH --chdir=.

# Set number of OpenMP threads
export OMP_NUM_THREADS=$SLURM_CPUS_PER_TASK

# Load modules environment
. /etc/profile.d/modules.sh

# Load trimAl module
module load trimal/1.2

# Input alignment file
INPUT="/mnt/data/mavila/ipereza/Porphyromonas_final/mafft/90/snpAlignment_porphyromonas90.fas_mafft.fas"

# Extract the base name from the file
BASENAME=$(basename "$INPUT" | sed 's/\.[^.]*$//')

# List of trimming methods
METHODS=("automated1" "gappyout" "noallgaps" "nogaps" "strict" "strictplus" "gt_cons")

echo "Starting trimAl processing..."
echo "------------------------------------------"
echo "Input file: $INPUT"
echo "Base name: $BASENAME"
echo "------------------------------------------"

for OPT in "${METHODS[@]}"; do

    echo "Processing method: $OPT"

    # Create output directory if it does not exist
    mkdir -p "$OPT"

    OUTPUT="$OPT/${BASENAME}_${OPT}.fas"

    case $OPT in
        "gt_cons")
            # Special combined case: gap threshold + consensus filter
            trimal -in "$INPUT" -out "$OUTPUT" -gt 0.8 -cons 60
            ;;
        *)
            # Standard trimAl predefined methods
            trimal -in "$INPUT" -out "$OUTPUT" -"$OPT"
            ;;
    esac

    echo "Finished method: $OPT"
    echo "------------------------------------------"

done

echo "All trimming methods completed."
echo "Output files saved in respective method directories with base name: $BASENAME"
```

## 32.3 Trimming methods
trimAl was used to remove alignment columns according to different gap-content and conservation criteria. The script applies seven trimming strategies to compare their effect on the alignment. 

| Method | Option | What it does |
| --- | --- | --- |
| **noallgaps** | *-noallgaps* | Removes only columns that consist entirely of gaps | 
| **nogaps** | *-nogaps* | Removes every column that contains at least one gap | 
| **strict** | *-strict* | Applies a stringent automated trimming criterion to remove poorly aligned regions |
| **strictplus** | *-strictplus* | Automated method similar to *strict*, but using a different procedure to select the thresholds | 
| **automated1** | *-automated1* | Heuristic method that picks the most suitable automated method for the alignment. Designed for maximum-likelihood tree inference | 
| **gappyout** | *-gappyout* | Automatically identifies and removes highly gapped regions based on the gap distribution of the alignment | 
| **gt_cons** | *-gt 0.8 -cons 60* | Retains columns in which at least 80% of sequences have no gap, while ensuring that at least 60% of the original columns are retained |
