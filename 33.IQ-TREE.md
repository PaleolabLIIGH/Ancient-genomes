## 33.1 Learn about IQ-TREE
To learn about IQ-TREE visit: https://iqtree.github.io/doc/

## 33.2 Evaluation of trimmed alignments
Run IQ-TREE on the Mafft alignment and on each trimAl-filtered alignment: 

```bash
# NOTE: replace the alignment filename with the name of the alignment that you are evaluating
iqtree -s snpAlignment80.fas_mafft_strict.fas -m MFP
```

Before inferring the tree, IQ-TREE prints a report on the alignment composition. It can be found at the top of the *.log* file

### 32.2.1 Reading the report
The report includes: 
* Number of sequences and alignment sites, distinct patterns, parsimony-informative sites, singleton sites, and constant sites.
* The percentage of gaps/ambiguous characters for each sequence.
* The result of the composition chi-square test for each sequence (sequences with p < 0.05 are marked as **failed**).

### 33.2.2 Interpreting the report and reviewing modern genomes
Check the gaps/ambiguity percentage and the composition test result of each sequence. High levels of gaps/ambiguity and **failed** results are expected in ancient samples because of DNA damage and low coverage, so these samples are retained. In modern genomes, if a modern genome is marked as **failed**, it is considered problematic and it is removed from the dataset and the analysis is repeated from the MultiVCFAnalyzer step. The new alignments are then re-evaluated with IQ-TREE, and this process is repeated until all moderns genomes are marked as **passed**.
