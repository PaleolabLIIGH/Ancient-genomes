## 32.2 Data Preparation

### 32.2.1 VCF Files
Before running the script, all raw **__'.vcf'__** and **__'.vcf.idx'__** files corresponding to the individuals included in the final IQ-TREE analysis must be placed within the same working directory where the script will be executed. **Make sure the filenames match exactly with the labels/names present in your IQ-TREE analysis.**

### 32.2.2 Reference FASTA Header Cleaning
The reference genome FASTA headers must be cleaned to retain only the main accession identifier, ensuring they match exactly with the chromosome/contig names in the __**merged.vcf.gz**__. Any text after the first space needs to be removed, as pathPhynder requires strict string matching between the VCF identifiers and the FASTA headers to work properly.

### 32.2.3 Phylogenetic Tree File
Pathphynder uses your final IQ-TREE phylogenetic tree as a backbone to perform the ancient linage placement. While you can specify the exact path to this file in the pathphynder script, the file requires a format adjustment beforehand.

IQ-TREE outputs the final tree with a __**'.treefile'**__ extension. You must ensure the file is saved as the standard **Newick format** with a **__'.nwk'__** extension so pathphynder can parse it correctly. **The tip labels (leaf names) inside the file have to match exactly with the filenames of your VCF files.**

### 32.2.4 Creating the Sample List
Pathphynder requires a plain text file containing the absolute paths to the trimmed BAM files of the ancient individuals you want to place on the phylogeentic tree. 

Create a file named __**'samples.txt'**__ containing one full file path per line.

#### Example of samples.txt
```bash
head samples.txt
```

## 32.3 Script
Once the **__'.vcf'__** files are in place, you can run the following slurm script to automate the compression, renaming and merging of the samples:

```bash
#!/bin/bash
#SBATCH --job-name=mergevcf
#SBATCH --output=mergevcf_%j.out
#SBATCH --error=mergevcf_%j.err
#SBATCH --mail-type=END,FAIL
#SBATCH --mail-user=danitzy2004@gmail.com
#SBATCH --cpus-per-task=10
#SBATCH --mem=5G
#SBATCH --ntasks=1

### Written by Itzy Perez

# Load environment modules
module load htslib/1.16
module load bcftools/1.17

# Search for vcf files in the current path
for name in *.vcf; do
    # Compress vcf files
    if [[ "$name" == *.vcf ]]; then
        vcf_recomp="${name}.gz"
        bgzip -c "$name" > "$vcf_recomp"
        # Update filename
        name="${name}.gz"
    fi

    # Save filename base
    base=$(basename "$name" .vcf.gz)
    out="${name%.vcf.gz}.renamed.vcf.gz"

    # Change header of the vcf
    bcftools reheader -s <(printf "%s\n" "$base") -o "$out" "$name"

    # Index vcf.gz
    tabix -p vcf "$out"

done

# NOTE: Replace this path with your own cluster directory containing the VCF files
find /mnt/data/mavila/ipereza/ParaC/vcfs_links -type f -name "*.renamed.vcf.gz" > vcf_list_renamed.txt

# Merge all VCF files in the list and index the final output
bcftools merge -l vcf_list_renamed.txt -O z -o merged.vcf.gz
bcftools index merged.vcf.gz
```
